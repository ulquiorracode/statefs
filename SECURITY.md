# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

We take the security of StateFS seriously. If you discover a security issue or vulnerability:

1. **Do not open a public issue.**
2. Send an advisory report via GitHub Private Vulnerability Reporting or contact the maintainers directly.
3. Provide detailed steps to reproduce the issue, along with proof-of-concept code or test cases.

Maintainers will respond promptly and coordinate a patch release.
